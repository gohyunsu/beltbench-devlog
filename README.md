# BeltBench Devlog

Static, local-first engineering record for the BeltBench workcell and benchmark.

Open `index.html` directly, or serve it locally:

```bash
cd <workspace-root>/beltbench-devlog
python3 -m http.server 8000
```

## Recording convention

- Add one page per issue under `issues/<area>/`.
- Include observed state, evidence, diagnosis, resolution, verification, and related issue links.
- Copy approved local evidence into `assets/images/`; retain originals in `../tmp/`.
- Keep all generated artifacts and edits under `<workspace-root>`.

ISSUE-002 · blocked · 2026-07-28

Camera calibration cannot begin until a capture path exists.

The xArm is online, but the current PC sees no camera. ParaDex expects FLIR/Spinnaker GigE cameras on one or more capture PCs, not a generic USB webcam.

Gate: do not run intrinsic, extrinsic, or hand-eye calibration until at least one camera is enumerated and its image stream is verified.

Observed state

CheckResult
/dev/video* and USB enumerationNo local V4L2/USB camera.
conda run -n camera ... PySpinPySpin imports successfully; Spinnaker enumeration returns count=0.
ParaDex1 capture-PC inventoryProfiles reference six capture PCs (the configured capture PCs) and FLIR serials.
ReachabilityOnly one responding host answered ICMP; its SSH and camera-service ports were closed.

Required recovery path

  1. Power and network the intended FLIR GigE camera(s), or boot the intended capture PC(s).
  2. On each capture PC, activate the PySpin environment and verify the serial list.
  3. Create the new active ParaDex system profile with only the actually present cameras.
  4. Run intrinsic calibration, then extrinsic, then xArm hand-eye calibration.

Hand-eye capture moves the live arm. It must be started only after the full camera calibration chain passes and the physical workspace has been cleared.

ISSUE-005 · 설계와 구현 · 2026-07-29

한 번의 자동 capture로 extrinsic과 hand-eye를 함께 얻는다.

기존 ParaDex calibration 흐름을 참고하되, BeltBench는 별도 process로 실행되는 작은 solver와 session format을 구현했다. 핵심 아이디어는 Charuco board를 xArm end-effector에 고정하고, robot이 안전한 여러 자세를 자동으로 순회하는 것이다.

목표: 사람이 board를 들고 작업 공간을 돌아다니는 대신, 승인된 xArm waypoint에서 multi-camera frame과 robot pose를 함께 저장한다. 각 fixed camera의 extrinsic과 board mount의 hand-eye transform을 같은 session에서 계산한다.

왜 두 calibration을 함께 풀 수 있나

각 pose에서 robot은 base_to_tool, camera는 Charuco PnP를 통해 camera_to_board를 제공한다. 둘은 같은 board를 설명하므로 다음 관계를 만족한다.

base_to_tool · tool_to_board = base_to_camera · camera_to_board

여기서 base_to_camera는 현재 xArm base 기준 camera extrinsic이고, tool_to_board는 end-effector에 장착한 board의 hand-eye transform이다. 여러 pose의 상대 운동으로 이 미지수를 풀고, 각 pose가 만든 해를 평균·residual 검증한다.

자동 capture의 안전한 순서

  1. 선정 camera의 기존 intrinsic을 board reprojection으로 검증한다.
  2. Charuco board를 end-effector에 단단히 고정하고, collision-checked waypoint를 준비한다.
  3. 각 pose에서 robot이 정지한 뒤 frame을 받아 corner 수가 충분한 camera만 session에 넣는다.
  4. 자세 회전이 충분히 다양하고 residual이 작은 camera만 calibration result로 채택한다.
  5. 결과를 current workcell의 private calibration manifest에 고정하고, 그 뒤에만 M0 observation에 사용한다.

현재 검증

독립 solver는 synthetic robot/camera transform에서 extrinsic과 hand-eye를 복원하는 test를 통과했고, 생성한 Charuco image에서도 corner detection과 PnP 경로를 검증했다. 아직 xArm SDK adapter와 selected-camera frame adapter는 연결하지 않았다. 이는 실제 robot motion 전에 waypoint와 workspace 안전을 별도로 확정하기 위해서다.

다음 구현

다음 단계는 xArm adapter의 move_joints·base_to_tool와 camera adapter의 read(camera_ids)를 연결하는 일이다. core solver를 바꾸지 않고 이 두 얇은 adapter만 추가하면 자동 capture session을 만들 수 있다.

관련 이슈

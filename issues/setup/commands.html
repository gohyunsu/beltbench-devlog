실행 순서를 한 곳에 고정한다.

BeltBench의 실행 코드는 private repository에만 있고, 이 페이지는 안전하게 재현할 수 있는 순서와 placeholder만 공개한다. network address, camera ID, calibration 수치, adapter transform은 각자 local configuration으로 제공한다.

1. 환경과 test

conda activate beltbench
cd /path/to/beltbench
python -m unittest discover -s tests -v

전용 environment에는 calibration, camera observation, xArm SDK, URDF visualization에 필요한 기본 의존성만 둔다. learned perception이나 GPU candidate generation은 별도 hardware requirement가 충족될 때 추가한다.

2. calibration

python scripts/capture_calibration.py +  --trajectory-dir calibration/trajectories/paradex2-xarm +  --camera CAMERA_A --camera CAMERA_B +  --intrinsics LOCAL_INTRINSICS.json +  --viewer-url http://127.0.0.1:VIEWER_PORT +  --host XARM_HOST --run-dir local/calibration/runs/RUN +  --confirm-trajectory paradex2-xarm +  --confirm-workspace-clear --execute

python scripts/calibrate.py local/calibration/runs/RUN/session.json +  --output local/calibration/runs/RUN/result.json

이 단계만 xArm motion을 포함한다. 승인된 trajectory, clear workspace, operator supervision 없이 실행하지 않는다.

3. two-camera observation

python scripts/capture_autodex_observation.py +  --camera CAMERA_A --camera CAMERA_B +  --intrinsics LOCAL_INTRINSICS.json +  --extrinsics REVIEWED_RESULT.json +  --viewer-url http://127.0.0.1:VIEWER_PORT +  --run-dir PRIVATE_DATA/observations/RUN +  --max-frame-age-s 2

observation은 fresh frame, calibration, image hash를 immutable artifact로 저장한다. 이 명령은 robot이나 hand에 motion을 보내지 않는다.

4. object dry-run과 3D inspection

python scripts/plan_object_dry_run.py +  --observation PRIVATE_DATA/observations/RUN/observation.json +  --object-config config/objects/OBJECT.json +  --data-root PRIVATE_DATA +  --workspace-min XMIN YMIN ZMIN +  --workspace-max XMAX YMAX ZMAX +  --output PRIVATE_DATA/plans/RUN.json

python scripts/visualize_grasp_proposal.py +  --proposal PRIVATE_DATA/plans/RUN.json +  --object-mesh OBJECT_MESH.obj +  --xarm-urdf XARM.urdf --inspire-urdf INSPIRE.urdf +  --tool-from-hand T00 T01 T02 T03 T10 T11 T12 T13 T20 T21 T22 T23 0 0 0 1 +  --xarm-joints Q1 Q2 Q3 Q4 Q5 Q6 +  --hand-joints H1 H2 H3 H4 H5 H6 +  --output PRIVATE_DATA/visualizations/RUN.glb

GLB에는 xArm, Inspire hand, adapter, object, selected wrist frame을 함께 넣는다. candidate generation과 collision/IK validation을 통과하지 않은 proposal은 visualization까지만 가능하며, execution은 차단된다.

안전 경계

  • camera·calibration·object asset은 local/private storage에 둔다.
  • dry-run과 visualization은 hardware motion을 호출하지 않는다.
  • candidate generation에는 CUDA와 complete object/robot scene asset이 필요하다.
  • 실제 execution은 collision-checked trajectory와 operator approval이 별도 필요하다.

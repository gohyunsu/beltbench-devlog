RUNTIME · 2026-07-30

GPU는 host에서 확인하고, runtime은 BeltBench에 고정한다.

처음에는 격리된 실행 환경에 GPU device node가 없어서 CUDA가 보이지 않았다. host 수준 probe로 GPU와 CUDA renderer를 확인한 뒤, 외부 checkout에 남아 있던 runtime source와 model을 독립 구조로 옮겼다.

확인된 것

  • host GPU와 CUDA renderer가 동작한다.
  • FoundationPose score/refiner checkpoint를 private model storage에서 GPU로 load했다.
  • BODex source는 private implementation repository의 third-party 영역으로 복사했다.
  • DA3 depth source와 model은 FoundationPose의 metric depth 입력을 위해 private model storage에 분리했다.

왜 source와 model을 나누나

실행 코드는 version-controlled private repository에 남기고, 큰 checkpoint와 raw experiment data는 private data root에 둔다. 따라서 Git history는 가벼운 코드·설정 중심으로 유지하면서도 runtime은 이전 AutoDex checkout이나 NAS path를 직접 읽지 않는다.

남은 재현성 이슈

원본 문서가 가리키는 MV-GoTrack fork와 두 tracking submodule은 현재 공개 접근이 불가했다. checkpoint만으로 tracker를 재현할 수 없으므로, 이 상태에서 tracking이 동작한다고 주장하지 않는다. 현재 FoundationPose initializer와 generic correspondence-to-PnP artifact path는 독립적으로 준비됐고, GoTrack source revision이 제공되면 같은 pose artifact contract에 연결한다.

안전한 검증 경계

여기까지는 model load와 offline runtime 검증이다. candidate generation, collision/IK, 실제 robot motion은 별도의 validated workcell input과 operator supervision 뒤에 수행한다.

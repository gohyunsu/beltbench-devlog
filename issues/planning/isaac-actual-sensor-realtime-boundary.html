ISSUE-073 · 2026-08-13 · Isaac actual-sensor real-time boundary

보여 주는 영상과 실제로 실행된 모듈을 분리해 첫 Isaac 센서 증거를 만든다.

교수 시연의 최우선 목표는 실제 카메라 입력부터 pose, planning, collision, controller까지 시간의 흐름에 따라 작동하는 modular pipeline이다. 기존 Viser는 완성된 reference를 설명하는 데 유용하지만 실제 perception 실행을 증명하지 못했다. 반대로 새 Isaac D0 실행은 실제 xArm6, Inspire Left, 두 connector CAD, Pepsi Light, conveyor, robot table, drop bin과 두 RGB-D camera를 한 scene에 올리고 실제 render product를 읽는다. D0는 이 sensor transport만 검증하며 pose나 grasp 성공으로 승격하지 않는다.

현재 판정: RTX 3090에서 6초 actual-asset RGB-D trial이 통과했다. Control-path RTF는 1.731, presentation 포함 RTF는 0.983이다. Pose, planning, controller authority는 모두 not_connected이므로 교수용 최종 integrated grasp demo는 아직 아니다.

모듈 경계

  1. Sensor edge: Isaac sensor와 이후 physical camera가 synchronized RGB, depth, mask, intrinsics, extrinsics, timestamp의 같은 observation contract를 구현한다.
  2. Pose acquisition: object와 stable pose가 선택된 상태에서 upstream RGB mask로 initial planar position과 yaw를 얻는다. FoundPose는 이 event-driven acquisition 후보이며 매 frame 기본 경로가 아니다.
  3. Constrained tracking: belt 이동 중 yaw가 고정되고 평행이동만 한다는 선언된 model 아래 depth-mask translation, camera disagreement, belt encoder와 covariance를 갱신한다.
  4. Resident decision: verified grasp/yaw/horizon atlas와 path family를 startup에 올리고 bounded maximin query만 수행한다. Unsupported cell은 fallback 없이 no_pick이다.
  5. GPU collision: exact remaining arm-hand command를 resident cuRobo gate가 검사한다. Timeout은 CPU fallback이 아니라 reject다. HPP-FCL은 offline named-mesh false-negative oracle로 남는다.
  6. Controller: 한 future-start arm/hand lease를 atomic하게 전달하고 simulator와 이후 robot adapter가 같은 계약을 소비한다.
  7. Evidence/presentation: trace serialization, Viser와 MP4 composition은 bounded queue 뒤의 비임계 consumer다.

이 수치가 증명하지 않는 것

  • Instance mask는 Isaac semantic capability이며 physical RGB segmentation 성능이 아니다.
  • Depth와 mask가 유효하다는 결과는 initial yaw 또는 execution-authoritative object pose가 얻어졌다는 뜻이 아니다.
  • Robot은 actual asset으로 보이지만 D0에서 command trajectory를 실행하지 않았다.
  • Connector 두 bore가 CAD assembly frame에서 정렬된다는 기존 검사는 physical bolt 체결 공차 측정이 아니다.
  • Presentation RTF 0.983은 control failure가 아니지만, live dashboard를 critical path에 넣어도 된다는 근거도 아니다.
  • 기존 full-task command의 release 한 frame collision failure가 남아 있어 planning pass를 표시할 수 없다.

FoundPose와 GoTrack의 현실적인 상태

RTX workstation에는 vendored FoundPose/GoTrack source가 있다. 그러나 Pepsi용 FoundPose object representation인 repre.pth와 필요한 pretrained artifact는 현재 project/evidence 영역에 없다. 따라서 다음 단계는 기존 source를 import했다고 선언하는 것이 아니라 Pepsi GLB를 checksummed mesh로 onboarding하고, 별도 beltbench-foundpose environment에서 cold/warm first-frame acquisition을 측정하는 것이다.

GoTrack은 previous-pose-conditioned refinement 후보이지 현재 기본 temporal path가 아니다. 공개 source의 README도 frame-to-frame optical-flow tracking이 구현됐다고 보장하지 않는다. Constant-yaw conveyor에서는 lightweight depth translation update가 더 작고 예측 가능하므로 original-cadence accuracy와 deadline 비교에서 이길 때만 GoTrack을 채택한다.

다음 구현 순서와 완료 조건

  1. D1 acquisition: Pepsi representation을 생성하고 rendered RGB/mask/intrinsics만으로 initial yaw와 position을 얻는다. Cold/warm latency, multi-view disagreement와 evaluator-only truth error를 기록한다.
  2. D1 tracking: Depth-mask world point update와 constant-yaw belt state를 15 Hz에 연결한다. 35 ms deadline, age, covariance, lateral/yaw residual gate를 통과해야 한다.
  3. D2 decision: Verified Pepsi upside-down grasp atlas와 path family를 resident load한다. Query 3 ms, changed candidate cuRobo gate 20 ms를 첫 workload로 측정하며 timeout은 reject한다.
  4. D2 correctness: 현재 release-frame collision defect를 고치고 exact command가 HPP-FCL oracle과 qualified cuRobo gate를 모두 통과해야 한다.
  5. D3 execution: 같은 future-start command로 Isaac articulation을 제어하고 measured contact, attachment, transport, release, bin containment와 stop을 기록한다.
  6. D4 presentation: Raw trace를 먼저 기록하고 MP4는 비동기 조합한다. 화면 stage color는 실제 event 전환을 따르며 artificial dwell을 넣지 않는다.

교수 시연에서 지금 보여줄 수 있는 범위

D0 MP4는 “실제 자산이 있는 Isaac scene에서 두 RGB-D sensor와 instance mask transport가 real-time control workload보다 빠르게 돈다”는 환경 통합 증거로 보여 줄 수 있다. 화면에 이미 D0 DIAGNOSTIC - NO POSE OR PLANNING AUTHORITY를 표시했다. 실제 grasp demo라고 설명할 영상은 D3 measured simulation을 통과한 뒤 별도로 만든다.

ISSUE-114 · 2026-09-01 · online attached collision authority

Nearest top-K는 유지하되 measured RGB command가 없으면 attached 검사를 시작하지 않는다.

정적 AutoDex grasp가 성공했고 현재 hand pose에 가깝다는 사실은 이동 grasp의 attach 이후 안전을 보장하지 않는다. Exact-context nearest는 후보 계산 순서로만 사용하고, observation 이후 새로 생성된 동일 command tensor의 attach→detach 구간을 robot-object와 object-world 연속 충돌로 다시 검사하도록 분리했다.

현재 효력: beltbench@58c3643은 attached partition의 exact source binding과 RTX preflight를 구현한다. 그러나 NAS의 positive motion artifact 8개가 모두 provisional_diagnostic 입력이어서 현재 command는 kernel 전에 거절됐다. 이것은 안전한 no-pick이며 실행 권한이나 attached latency 결과가 아니다.

Nearest grasp의 정확한 역할

단계사용 여부판정 기준
Retrieval사용동일 object, inferred stable pose, hand, capability와 qualification 안에서 predicted intercept별 top-K를 다시 계산한다.
Motion generation순서로만 사용각 grasp/time pair를 현재 robot feedback에서 fresh full command로 생성한다.
Attached collisionrank 미사용동일 command tensor, grasp SHA, prediction, connector, robot, object와 workcell source를 검사한다.
Final selection미사용모든 partition을 통과한 handoff-feasible command의 robust maximin으로 결정한다.

따라서 nearest grasp 자체를 금지할 이유는 없다. 금지 대상은 nearest-1 직접 실행, 다른 stable pose나 hand로의 fallback, acquisition 시점 rank 재사용과 nearest distance를 final score에 넣는 것이다.

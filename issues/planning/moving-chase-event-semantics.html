ISSUE-031 · 2026-08-09 · moving chase semantics

첫 물리 접촉과 물체 부착을 분리하고, 그 사이 전체 구간에서 손이 물체를 실제로 따라가는지 검증한다.

Endpoint grasp가 정적으로 유효하고 접촉 순간의 pose와 velocity가 맞더라도, 손을 닫는 동안 물체가 계속 이동하면 중간 구간에서 손이 뒤처질 수 있다. 기존 path-family의 contact는 사실상 attach 시각이었고 새 event trajectory의 contact는 첫 물리 접촉이어서 같은 단어가 서로 다른 상태 전이를 뜻했다. 이번 구현은 공통 사건 계약, 명시적 contacting 상태와 bounded chase 검증으로 이 의미 충돌과 endpoint-only 허점을 닫는다.

현재 효력: source commit 1bf2269이 공통 moving-pick 사건, actual-time reference와 complete chase interval의 재현 가능한 sampled evidence를 구현하고 over-capacity grid를 allocation 전에 거부한다. 이 결과는 필요한 진단 gate이지만 continuous collision, controller tracking bound와 hardware 결과가 없으므로 execution_blocked를 유지한다.

BeltBench의 실제 gate 계층

  1. Proposal: 생성기 success와 residual은 provenance이며 승인 점수가 아니다.
  2. Intrinsic endpoint: named allowed contact, 최소 contact 수, penetration, self·support·non-contact clearance와 task wrench margin을 검사한다.
  3. Intrinsic path: object-relative approach·closure·release 경로 전체를 검사한다. Endpoint 성공으로 중간 실패를 덮지 않는다.
  4. Robot deployment: 정확한 arm·hand·connector·object·workcell 조합에서 IK, joint·singularity margin과 assembly·scene clearance를 검사한다.
  5. Yaw·horizon atlas: 관측된 초기 yaw uncertainty와 가능한 intercept horizon 전체에서 hard-gated grasp 교집합만 반환한다.
  6. Path family: task와 cutoff stop path, tracking·correction tube, latch, deadline과 complete phase를 검증한다.
  7. Moving contact: 첫 접촉부터 attach까지 pose·상대 선속도·상대 각속도가 허용 tube 안에 유지되는지 검사한다.
  8. Selection: 모든 hard gate를 통과한 후보만 normalized robust slack의 deterministic maximin으로 비교한다.
  9. Physical authority: fresh synchronized observation, controller tracking·latency, calibration error와 hardware reliability는 별도 gate로 남긴다.

따라서 이번 변경은 grasp quality score를 하나 더 더한 것이 아니다. 정적 grasp와 동적 실행 가능성을 서로 다른 권한으로 유지하고, 동적 접촉 구간의 필수 반례를 잡는 독립 evidence를 추가한 것이다.

사건과 물체 상태

MovingPickEventSchedule이 path-family와 event trajectory가 공유하는 유일한 사건 의미를 소유한다.

replan_cutoff ≤ hand_close_start < first_contact < hand_close_complete ≤ attach

  • first_contact: 허용된 hand link가 처음 물체에 닿는 시각이다.
  • hand_close_complete: 선택 grasp의 닫힘 command가 끝나는 시각이다.
  • attach: grasp constraint가 성립해 물체가 tool-relative pose로 전환되는 시각이다.
  • contacting: 첫 접촉부터 attach 전까지 물체는 belt에 지지되며, 손과 물체의 intentional contact가 필수다.
  • attached: attach 이후 물체는 tool을 따라가며, 설정된 최소 intentional contact가 필수다.

현재 path-family bundle schema는 6.0이다. Validator는 첫 contacting sample이 정확히 first_contact, 첫 attached sample이 정확히 attach인지 검사한다. Runtime의 scheduled contact와 cutoff 판단도 같은 nested schedule을 사용한다.

Complete chase interval

MovingChaseAssessment는 첫 접촉과 attach endpoint만 비교하지 않는다. 두 시각 사이를 policy가 정한 최대 간격으로 deterministic sampling하고, hand_close_complete를 grid에 정확히 삽입한다. 각 sample에서 exact arm·hand state의 FK/Jacobian과 예측 object pose·twist를 이용해 다음 네 metric의 최악값과 발생 시각을 기록한다.

  • Object-from-tool 기준 translation error
  • Object-from-tool 기준 rotation error
  • 손과 물체의 relative linear speed
  • 손과 물체의 relative angular speed

Draft policy는 최대 sample 간격 0.01 s, 최대 1001개, translation 5 mm, rotation 2 deg, relative linear speed 0.03 m/s, relative angular speed 0.1 rad/s다. 숫자는 hardware 측정 전 보수적 초안이며, threshold 출처와 status를 artifact에 명시한다. Sampling 간격만 받고 개수 상한이 없으면 비정상 event duration이 latency와 memory를 무한히 늘릴 수 있으므로 둘 다 hard bound로 둔다.

현재 운동 모델은 tabletop pose와 초기 yaw가 고정되고 물체가 belt 방향으로 평행이동한다는 가정이다. Object angular velocity가 0이 아니면 evaluator가 명시적으로 거부하며 조용히 translation-only model로 투영하지 않는다.

Artifact 결속과 시각화

Assessment는 exact event trajectory, moving-contact artifact와 chase policy의 SHA-256을 저장하고 verifier가 내용을 다시 계산한다. 중간 sample만 크게 벗어나고 두 endpoint가 일치하는 trajectory도 실패한다. Actual-time reference는 별도 legacy playback 변환 없이 exact timeline에서 직접 sampled path를 생성해 모든 waypoint와 사건을 보존한다.

Viser는 선택적으로 chase assessment를 받아 sample 수, 최대 간격, 네 metric의 pass/fail, bottleneck과 worst time을 표시한다. 표시 전에 trajectory와 contact digest를 다시 확인한다. 이것은 계획된 reference와 offline evidence의 재생이며 controller command나 measured trajectory로 표시하지 않는다.

검증 결과

  • Planning 환경의 full discovery는 444개를 수집했고, OpenCV import 3개를 제외한 441개가 통과했다.
  • 분리된 calibration 환경에서 해당 OpenCV 의존 module의 실제 test 14/14가 통과했다.
  • 최종 local 영향 범위는 moving contact·chase·event trajectory와 path-family engine 42/42가 통과했다.
  • Middle divergence, nonzero object angular velocity, digest 치환, sample capacity와 event insertion negative test가 통과했다.
  • Visualization 환경에서 Viser CLI가 optional --moving-chase-assessment 입력을 노출하고 import가 통과했다.
  • Line length, stale event field, 제거된 legacy converter reference와 git diff --check를 다시 검사했다.
  • junjinyong A6000 focused PBS 115186은 source e0c1cdd에서 28/28, scheduler exit 0을 기록했다.
  • 표준 CPU-only planning regression PBS 115187은 최종 source 1bf2269에서 42/42, scheduler·run status exit 0을 기록했다.
  • 115187의 compute clock은 run filesystem보다 367초 느려 timing_evidence_authorized=false다. 따라서 test 기능 통과만 근거로 사용하고 1.399초 test runtime을 latency 근거로 사용하지 않는다.

남은 권한과 다음 순서

  1. Closing hand의 실제 link geometry를 포함한 continuous/swept self·object·belt·table collision을 검증한다.
  2. Interception window, closure 시간, attach와 deadline을 동시에 만족하는 bounded schedule allocator와 time parameterizer를 구현한다.
  3. Chase assessment를 compiled path admission에 연결하되 continuous path evidence가 없으면 계속 차단한다.
  4. 실제 xArm·Inspire trajectory로 controller tracking tube, latency와 hand close repeatability를 측정한다.
  5. Calibration residual과 belt speed uncertainty를 chase threshold 및 robust slack에 전파하고 hardware moving-pick reliability를 별도 승인한다.

관련 맥락은 AutoDex filter와 task-event 감사, synchronized event trajectory, path validation authority에서 이어진다.

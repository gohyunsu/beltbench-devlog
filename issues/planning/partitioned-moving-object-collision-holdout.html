ISSUE-113 · 2026-09-01 · partitioned moving-object collision holdout

Moving-object collision을 GPU 보수 근사와 exact mesh의 명시적 분할로 검증한다.

Nearest grasp top-K는 후보를 빠르게 줄이는 데 유효하지만, 현재 RGB pose와 robot state에서 새로 만든 trajectory의 안전을 보장하지 않는다. 이번 단계는 움직이는 물체, robot, conveyor와 table의 시간별 관계를 동일 corpus에서 검사하고, cuRobo와 HPP-FCL이 소유할 collision domain을 겹침 없이 고정한 뒤 독립 holdout에서 false negative 0을 확인했다.

현재 효력: beltbench@c42f445는 final-holdout-qualified threshold gate와 source-derived sphere prefilter를 relative-motion-bounded continuous interval certificate로 합성했다. RTX 3090에서 1,800-waypoint command의 0--9초 pre-attach partition을 113.463 ms에 검사했지만 attached/release/dynamics, complete candidate batch, maximin과 controller handoff는 아직 합성되지 않았으므로 execution_authorized=false다.

Fresh online command와 prediction을 직접 결속한다

7185d8d 이전의 연속 gate는 resident full-command lifecycle에서는 source-closed였지만, online exact-command validator의 workspace를 직접 받는 계약이 없었다. 따라서 실제 RGB·encoder prediction 이후 새로 만든 candidate command에 같은 검사를 적용하려면 caller가 timeline hash, attach pose와 속도를 따로 전달해야 했다. 이 경계는 잘못 조합한 command와 prediction을 구조적으로 막지 못하고, RGB pose covariance도 clearance에 반영하지 못한다.

새 OnlinePreAttachDynamicObjectInput은 candidate, event command, 이름 순서가 결속된 command tensor, intercept, measured motion-prediction 전체 evidence, object model, stable pose와 grasp를 한 digest로 묶는다. Adapter는 backend-owned opaque factory를 통과한 workspace만 받으므로 component마다 깊은 request graph를 다시 검증하지 않으면서 caller가 임의 workspace를 검증 완료로 표시할 수 없다.

Encoder prediction을 완전한 등속으로 가정하지도 않는다. Command start와 attach 사이의 prediction knot 전체에서 start-to-attach secant 잔차를 측정하고, translation 잔차와 object bounding radius로 환산한 rotation 잔차를 nominal continuous clearance에서 차감한다. 같은 구간 pose covariance의 translation·rotation trace도 policy의 표준편차 배수로 거리 inflation으로 변환한다. 따라서 nominal gate가 통과해도 model residual 또는 pose uncertainty가 policy를 넘으면 해당 partition은 reject된다.

Nearest grasp에 대한 결론

Nearest grasp는 제거하지 않는다. Exact object, inferred stable-pose class, hand, capability와 evidence를 먼저 hard gate하고 predicted intercept마다 현재 RGB pose와 robot FK로 bounded top-K를 다시 계산하면 효율적인 proposal/solver order다. 금지하는 것은 nearest-1 직접 실행, acquisition 시점 rank 재사용, 다른 stable pose/hand fallback과 nearest distance를 final score에 넣는 것이다. 각 grasp/time pair는 fresh full command를 만들고 동일 tensor의 모든 partition을 독립 검증한 뒤 nearest-rank-independent robust maximin으로 선택해야 한다.

Nearest online data plane과 partitioned self-collision을 함께 보면 후보 검색, 정적 robot 충돌과 움직이는 object 충돌의 권한 경계를 구분할 수 있다.

ISSUE-018 · 2026-08-08 · reusable path contract

Grasp endpoint가 아니라 완전한 reusable path 증거가 있을 때만 online 후보로 남긴다.

기존 yaw atlas는 특정 grasp가 sampled endpoint context에서 유효했음을 보이지만 현재 robot state에서 contact·lift·drop·stop까지 이어지는 경로를 보장하지 않는다. Atlas를 곧바로 online exact planner에 전달하는 구조 대신, atlas를 절대로 넓히지 않는 execution-blocked path-family deployment bundle 계약을 추가했다.

현재 효력: f7a0046은 compiler 출력 schema와 startup source/atlas verification을 정의한다. 실제 path compiler, report 재계산, resident runtime query, controller commit은 없으므로 real-time path execution이 구현된 상태가 아니다.

구현한 bundle

  1. ConveyorPathSupportEnvelope는 family가 실제 지지하는 atlas context 교집합과 lateral·speed·intercept·horizon closed interval을 명시한다.
  2. PathValidationEvidence는 self/environment/nonintentional-object clearance, joint·singularity margin, normalized dynamics·timing slack, phase와 validator report source를 분리한다.
  3. CompiledConveyorPathFamily는 exact grasp, complete task phase, reusable/stop path, hand-close/contact timing, cutoff 이전 latch region과 post-cutoff correction tube를 묶는다.
  4. PathFamilyDeploymentPolicy는 resident/query family 수, robot-state age, warm-start 1회와 fixed compute budget, switching improvement를 bounded config로 고정한다.
  5. PathFamilyDeploymentBundle은 arm·hand·connector·object·stable pose·task·calibration·workcell·atlas identity를 고정하며 항상 execution-blocked다.

검증과 fail-closed 규칙

  • Path family는 atlas registry의 grasp만 사용하고, 지원한다고 선언한 모든 context에서 그 grasp가 실제 candidate였어야 한다.
  • Unknown context, neighboring context borrowing, interval relaxation, missing phase, sampled/continuous scope mismatch를 거부한다.
  • Latch region의 tolerance까지 cutoff 이전에 끝나야 하며 hand-close start < completion ≤ contact < path end 순서를 강제한다.
  • Warm start attempt는 정확히 1회이고 compute duration은 policy에 고정된다.
  • Bundle·family·latch·path·stop·tube·validation source를 re-hash하고 exact policy와 atlas source를 다시 확인한다.

검증 결과와 남은 위험

Bundle round-trip/write-once, policy example, support intersection, unknown context/grasp, context-grasp substitution, timing, cutoff, bounded warm start, source checksum mutation을 검사했다. Path-family·robot-motion·atlas 집중 test 29개가 통과했다.

전체 planning 수집 275개 중 OpenCV 전용 import 3개를 제외한 실제 272개와 calibration 14개, 총 286개가 통과했다. junjinyong 서버 고정 환경에서도 관련 41개가 통과했다.

아직 실제 path file이나 continuous tube report는 생성되지 않았다. 다음 runtime query에서 active path retain은 latch box가 아니라 별도 continuous tracking-tube evidence를 요구해야 한다. Cutoff 전에는 retain→latch→fixed-budget warm start, cutoff 후에는 bounded phase correction 또는 abort만 허용한다.

Controller-grade latch state가 이 bundle의 current-state 입력이며, architecture ADR이 다음 runtime query의 권한 순서를 정의한다.

ISSUE-071 · 2026-08-13 · connector and precommand timeline audit

Connector hole을 수치로 다시 맞추고 command 앞에 upstream inference budget을 분리했다.

기존 Viser는 tmp/xarm_base.obj와 tmp/inspire_base.obj를 흰색으로 표시했지만, 두 부품의 나사 구멍이 실제로 이어지는지와 물체가 왜 arm 바로 앞에서 시작하는지를 설명하지 못했다. 원본 OBJ의 disconnected cylindrical shell을 직접 fitting해 네 radial bore가 identity assembly에서 이어짐을 확인했다. 별도로 26.288853초 exact command를 바꾸지 않고, 물체가 belt 상류에서 들어오는 3.3초 precommand timeline을 source-bound evidence로 추가했다.

현재 판정: 두 connector CAD 사이 radial bore 정렬은 tessellated mesh 좌표에서 4/4 통과한다. 그러나 flange datum, thread, tolerance와 실물 조립 계측은 없으므로 connector는 계속 provisional이다. 새 acquisition·tracking·planning 구간도 실제 perception 실행이 아니라 provisional_timing_budget이며 real-time 성능 증거가 아니다.

발생한 문제와 원인

관찰원인잘못된 대응의 위험
두 base의 hole 중심이 서로 다른 반경에 보였다.xArm 측 bore는 반경 약 9.86-15.00 mm, Inspire 측 bore는 약 14.91-20.00 mm를 차지하는 연속 구간이다. 같은 hole의 두 segment이므로 component centroid는 달라야 한다.Centroid를 억지로 겹치면 두 부품을 약 5 mm 이동시켜 실제 bore axis와 press-fit 경계를 깨뜨린다.
Manifest의 두 mesh pose가 identity여서 근거 없는 fallback처럼 보였다.두 OBJ는 같은 assembly frame으로 export됐지만 그 사실을 checksum과 renderer 배치만으로 표현했다.눈으로만 판단하면 renderer bug와 실제 CAD 불일치를 구분할 수 없다.
v3 물체가 Y=-0.176 m에서 시작했다.Playback이 perception 완료 뒤 command 시작을 frame zero로 사용했다. Belt 속도는 +Y 0.08 m/s이고 contact까지 1.8초만 표시했다.Camera acquisition, initial yaw, track initialization과 planning latency가 이미 검증된 것처럼 오해된다.
Perception 시간을 command JSON에 직접 앞붙일 수 있었다.시각화 시간과 controller command 시간을 한 artifact로 섞기 쉽다.기존 q/qd/qdd, event time, collision frame index와 source digest를 모두 다시 해석하게 된다.

Connector 재검증

서버 private asset과 workspace tmp 원본의 SHA-256은 각각 정확히 일치했다. xArm OBJ는 39개, Inspire OBJ는 21개의 non-watertight component로 export됐다. PCA 기반 open-cylinder fitting은 축 방향 길이가 직경보다 길고 normalized radius residual이 0.03 이하인 radial shell을 찾는다. 그 다음 두 mesh의 축 collinearity, 직경 차이와 axial interval gap을 비교한다.

선택한 시간축 경계

PrecommandTimelinePolicy는 belt velocity와 단계별 budget만 소유한다. 생성된 evidence는 exact source playback ID와 canonical SHA-256, policy SHA-256, 유도된 entry pose와 belt 중심 여유를 보존한다. Viewer는 lead-in 동안 첫 robot command를 hold하고 object만 평행이동시킨다. 3.3초 이후에는 source playback time을 0초부터 그대로 사용하므로 event request와 기존 HPP-FCL frame index는 바뀌지 않는다.

남은 gate

  1. Saved multi-camera frames 또는 live sensor에서 acquisition, FoundPose/FoundationPose, yaw와 fused tracking trace를 기록해 provisional stage를 measured p50/p95/p99로 교체한다.
  2. Entry admission에 object footprint, yaw support와 pose covariance를 포함해 belt edge chance constraint를 검사한다.
  3. 100 ms planning budget은 요구사항이다. Resident atlas/curobo adapter의 end-to-end observation-to-terminal benchmark와 deadline miss를 별도로 측정해야 한다.
  4. Connector는 STEP datum 또는 CMM/assembled metrology로 flange, mating surface와 fastener axis를 측정하기 전까지 execution gate를 열지 않는다.
  5. Source command의 HPP-FCL 1-frame release 실패는 그대로 남아 있다. Lead-in을 추가해 이를 숨기지 않는다.

ISSUE-105 · 2026-08-30 · asymmetric target-hand pick atlas

대칭 물체 baseline을 넘어 Banana의 full-yaw pick 가능 영역을 source-close한다.

NAS의 물리 시행, stable-pose scene, mesh와 target-hand 후보를 다시 비교해 첫 비대칭 시연 객체를 banana/source-001로 고정했다. Inspire Left의 정적 성공 prior를 별도 보존하고 187개 proposal을 독립 평가한 뒤, xArm6 endpoint를 12 yaw와 3 intercept horizon에서 검사했다. 최종 atlas는 36 cell 중 18개와 grasp 1개를 보존하며 1,124개 source를 재검증했다. 이 결과는 pick-only endpoint coverage이며 RGB pose, complete moving trajectory, contact dynamics와 hardware 실행 권한은 포함하지 않는다.

이 선택은 형상이 어려워 보이는 순서가 아니다. Target hand의 실제 시행, stable-pose mapping ambiguity, mesh validity와 비대칭성을 동시에 충족하는지를 기준으로 했다. 보관된 v7 candidate에는 episode result directory가 없으므로 모든 proposal을 성공으로 승격하지 않았다. 성공 7개는 summary 기반 static physical prior, 187개 candidate는 outcome-unknown proposal로 분리했다.

Capability를 먼저 분리했다

두 intrinsic survivor는 접근·closure·retention의 정적 pick geometry는 통과했지만 release path failure가 남았다. Drop-release를 요구하면 worklist가 비어 robot endpoint를 평가할 수 없었다. Release gate를 지우는 대신 pick_only → robot endpoint → dynamic retention/release → drop admission 순서로 단계를 분리했다.

434a04b와 6a320d9는 deployment verifier도 policy의 capability-specific worklist를 재구성하게 했다. 실제 nominal assessment는 92개 source를 검증했고 후보 2개×horizon 3개가 모두 pregrasp_ik에서 실패했다. 이를 object 실패로 확대하지 않고 단일 yaw robot context의 negative evidence로 제한했다.

Full-yaw endpoint 결과

8455965는 대칭 축소가 없는 30° 간격 12 yaw, 4.6/4.8/5.0초 horizon, pick_only hard gate를 선언했다. Upstream에서 0.04 m/s로 들어오는 object observation으로 12개 prediction을 생성했고 23개 source를 독립 재현했다. 같은 model context를 한 번 준비한 batch evaluator가 모든 yaw를 순서대로 검사했다.

Benchmark는 startup source verification과 atlas load를 제외한 resident lookup만 측정한다. Accepted query는 sampled endpoint cell에 공통 grasp가 있다는 뜻이며, complete trajectory, timing, moving collision, contact, stop path나 controller handoff가 통과했다는 뜻이 아니다.

권한 경계와 다음 단계

  1. Stable pose와 conveyor calibration은 provisional이다. Simulation에서는 exact source를 사용하되 physical deployment에는 measured plane, travel direction과 robot-base transform이 필요하다.
  2. 현재 입력 yaw는 offline grid다. Isaac RGB sensor에서 banana mask, stable pose, planar position, full yaw와 covariance를 실제 runtime contract로 생산해야 한다. Ground-truth prim pose는 평가에만 사용한다.
  3. Atlas가 반환한 candidate를 latest robot state와 timestamped object prediction에 배치하고, cuRobo resident batched IK/collision과 independent complete-path validator로 moving prefix·retention·abort를 검사해야 한다.
  4. Release failure는 남아 있다. 첫 영상은 pick-only guarded retention까지 분리해 검증하고, bin drop은 dynamic opening·detach·containment qualification을 통과한 뒤 추가한다.
  5. 교수용 영상은 actual RGB perception과 online atlas decision이 같은 trace에 연결되고 Isaac articulation/contact feedback이 실제 command를 실행할 때만 새 positive evidence로 채택한다.

Full-yaw batch 원칙, RGB-only 관측 계약, grasp qualification 경계가 관련 설계를 설명한다.

ISSUE-084 · 2026-08-24 · runtime-profile-bound Isaac rerun audit

14단계 runtime profile을 실제 Isaac evidence에 결속하고 실패 run을 그대로 감사한다.

통합 영상에 단계 이름만 표시하는 대신, pipeline profile의 identity·deadline·실행 상태를 staged manifest와 report에 source-closed하게 결속했다. 이어서 acquisition gate, encoder ingress, current-state estimation, future projection과 resident decision을 독립 계측하고 authoritative trace를 영상 조립에서 분리했다. RTX 3090에서 실제 Isaac RGB-D, FoundPose, CAD tracking, exact command selection과 PhysX articulation servo를 반복 실행했으나 최신 source의 presentation은 FoundPose yaw repeatability와 단일-yaw command cell 때문에 최종 acceptance를 통과하지 못했다.

현재 판정: revision 9c7a7e0에서 profile v2의 일곱 D1 authority stage와 bounded trace timing은 통과했다. r83/r84/r86은 같은 command yaw 조건에서 repeatability failure를 재현했고, qualification-grid 조건 r85도 measured yaw와 단일 prevalidated command의 nominal yaw가 달라 선택되지 않았다. 교수님께 제시할 accepted 기준선은 계속 r72다. 아래 r81은 실제 perception과 servo animation이 완주됐지만 timing gate를 통과하지 못한 진단 영상이다.

테스트와 재현성

로컬 focused suite는 57개, publisher 후속 suite는 15개가 통과했다. RTX Linux HPP-FCL environment에는 깨진 pip shebang이 있어 해당 interpreter의 python -m ensurepip로 복구한 뒤 pytest를 설치했다. 서버 전체 회귀는 1,103 passed, 15 skipped, 45 subtests passed다. 로컬 전체 pytest는 코드 실행 전에 WSL p9_client_rpc collection 대기에서 403초 정지해 중단했고, 동일 revision의 Linux 전체 suite로 대체했다.

r82 command/playback/report hash는 4c40289f…, 39e79cca…, 56f9ac16…이고 independent validation/audit hash는 b75f7319…, 745eddc0…다. r81 presentation report/video hash는 45d05706…, ea454005…다. r83/r84/r85/r86 report hash는 각각 ddae97cb…, c4e739df…, 9a9e858f…, d02b9cf1…다. 원본 report는 내부 절대 경로와 계정명을 포함하므로 public site에는 복사하지 않았다.

남은 blocker와 다음 순서

  • FoundPose full-yaw qualification 최대 오차 0.1018 rad와 runtime repeatability가 command gate 0.08 rad보다 나쁘다. 같은 frame의 두 camera가 서로 동의해도 함께 틀릴 수 있으므로 camera-consensus만으로 해결되지 않는다. Upstream temporal reacquisition 또는 texture-aware yaw refinement를 구현하고 original cadence에서 반복 검증해야 한다.
  • 현재 prevalidated command는 nominal yaw 하나만 갖는다. 임계값을 완화하기보다 yaw/context별 source-closed path family를 offline compile하고, online에서는 measured yaw와 uncertainty가 포함되는 validated cell만 선택해야 한다.
  • Trace publisher와 video assembly는 분리됐고 authority timing은 통과했다. 그러나 no-pick가 1,000회 반복되는 presentation에서는 JSON snapshot과 반복 decision이 함께 증가한다. Reject reason이 불변이면 decision을 event-driven으로 retain하고 trace schema도 고정-width field layout으로 줄이는 최적화가 필요하다.
  • Controller feedback profile은 2 ms로 통일했고 accepted-command run에서 충분한 margin을 확인했다. 실제 hardware claim 전에는 future-start lease, controller-native clock과 stop budget을 별도로 구현해야 한다.
  • correction_envelope, resident cuRobo gate, future-start controller handoff와 measured lifecycle이 아직 없다. 이 네 단계를 구현하기 전 complete real-time inference demo를 주장하지 않는다.
  • 현재 영상은 rigid-object contact, attachment, slip, release와 bin containment를 측정하지 않는다. Full-task 영상은 release/contact schedule과 simulator dynamics가 같은 source-closed command에서 통과한 뒤 별도 생성한다.

ISSUE-099 · 2026-08-28 · retained BODex Left batch reuse

처음부터 다시 생성하지 않고 보존된 512개 Inspire Left seed를 source-close한다.

Shared AutoDex Right 후보는 Left 재최적화 seed로 활용하고, 이미 RTX 서버에 남아 있는 Inspire Left raw seed는 현재 frame 계약으로 재수입한다. 두 경로 모두 offline이며 event-time runtime은 NAS를 검색하지 않는다.

현재 판정: BeltBench 27e84be에서 synthesis request와 import config 자체를 proposal source evidence로 추가했다. 서버의 512개 raw seed를 다시 생성하지 않고 전량 재수입했으며 2,571개 source reference를 재해시했다. 512개 proposal ID, object-relative root, hand command와 metric은 이전 artifact와 동일했다. 아직 qualified grasp는 아니며 NAS 정식 snapshot과 현 protocol 재평가가 남았다.

문제원인해결 및 결과
Proposal만으로 root-frame 변환을 재현할 수 없음기존 batch는 staging과 preflight를 묶었지만 import config와 synthesis request 파일 자체는 source evidence에서 빠졌다.Importer가 두 파일을 다시 로드해 전달 객체와 비교하고 SHA-256 evidence에 포함하도록 변경했다.
문서에는 2,000/140/117이 current baseline처럼 기록됨계획 seed count와 보존되지 않은 과거 worktree 결과가 실제 retained artifact와 혼재했다.서버와 NAS의 모든 proposal JSON을 집계해 최대 보존 batch가 512개임을 확인하고 문서를 512/46/44/106으로 교정했다.
새 artifact와 과거 proposal payload가 전체 비교에서 다름출력 위치가 달라 각 raw source의 상대 경로 문자열이 달라졌다.필드별 비교 결과 512건 모두 차이는 source_files.reference뿐이었다. ID, root, command, metric과 source SHA는 동일했다.
Local conda test launcher 실패Read-only sandbox에서 conda가 사용할 임시 디렉터리를 만들 수 없었다.쓰기 승인 환경에서 인접 BODex 회귀 40/40을 통과했고 RTX BODex 환경에서도 importer 16/16을 통과했다.

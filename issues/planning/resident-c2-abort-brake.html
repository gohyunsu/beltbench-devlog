ISSUE-094 · 2026-08-27 · source-bound resident C2 braking

Hold fixture를 비영속 경계조건에서 출발하는 검증 가능한 제동 후보로 교체한다.

Phase-aware slot과 controller는 구현됐지만 route 내용은 첫 sample 뒤 속도와 가속도를 0으로 바꾸는 unit fixture였다. 이 구조로는 실제 moving command에서 C2 연속성, jerk와 정지 위치를 설명할 수 없으므로 online fallback 없이 offline deterministic brake producer를 추가했다.

현재 판정: revision 46fcb97에서 exact latch q/qd/qdd를 보존하는 shortest-feasible C2 brake를 구현했고 local 및 RTX 회귀 32/32를 통과했다. 이 결과는 motion-limit-valid candidate이며 collision·terminal-region 또는 실행 권한이 아니다.

발생한 문제와 영향

문제영향
기존 abort command는 hold fixture였다.Selector와 slot 전환은 시험할 수 있지만 실제 이동 중 정지를 계획했다는 증거가 없었다.
Nominal suffix를 자르거나 즉시 hold하는 방안이 남아 있었다.Latch 속도·가속도가 0이 아니면 command 경계가 끊기고 controller impulse를 숨기게 된다.
Fault 시 online global planning을 호출할 가능성이 있었다.Perception이나 tracking이 이미 불안정한 시점에 가변 latency와 새 failure mode가 추가된다.
실제 r627 command는 최신 resident source chain으로 컴파일되지 않았다.새 planner가 있어도 production Pepsi route를 바로 생성하거나 설치할 수 없다.

선택한 방법

  1. Nominal latch의 arm position, velocity와 acceleration을 첫 boundary로 그대로 사용한다.
  2. Terminal velocity, acceleration과 jerk가 모두 0이 되는 normalized-time quintic의 나머지 계수를 해석적으로 푼다. Terminal position은 강제로 home을 지정하지 않고 이 제동 해에서 결정한다.
  3. 정책에 선언된 duration grid를 짧은 순서로 탐색한다. 가능한 첫 후보만 선택하므로 생성 latency와 정지 시간을 불필요하게 늘리지 않는다.
  4. 각 polynomial의 critical root를 구해 연속시간 joint position, velocity, acceleration과 jerk peak를 계산한다. Sample 점만 통과하는 후보는 승인하지 않는다.
  5. Hand는 latch에서 이미 stationary여야 하며 exact position을 유지한다. Arm뿐 아니라 고정 hand position도 joint-limit margin에 포함한다.
  6. Policy, 실제 produced full-command output, validated producer lease, motion-limit profile, terminal state, extrema와 exact sample digest를 planner result에 결속하고 abort command가 그 result digest를 참조하게 한다.

배제한 대안

  • Nominal truncation/freeze: 독립 경로가 아니고 nonzero derivative를 지워 C2 경계를 위반하므로 배제했다.
  • 항상 home retreat: 더 긴 경로와 추가 collision risk를 만들며 attached object를 유지해야 하는 fault에는 부적절하다.
  • Fault 후 cuRobo global solve: 안전 반응의 latency를 비결정적으로 만들기 때문에 runtime abort mechanism으로 사용하지 않는다.
  • Contact/release를 brake가 생성: irreversible lifecycle 의미론을 수치 제동기가 추측하게 되므로 배제했다. 기존 certified command를 attached 또는 contained latch까지 완료한 뒤 brake를 시작한다.

재검토 중 발견한 누락

첫 구현은 arm polynomial의 연속시간 limit만 계산하고, 움직이지 않는 hand의 position limit은 암묵적으로 nominal source에 의존했다. 그러면 “전체 command motion limits checked”라는 결과가 과장된다. Fixed hand position의 normalized joint-limit margin도 동일한 hard gate에 포함하고, 범위 밖 hand fixture가 fail-closed하는 시험을 추가했다.

실제 r627 source audit

r627 runtime admission이 참조한 independent validation digest는 r223 계열의 동일 파일로 확인됐다. 이 파일은 1,265개 full-frame sampled collision을 통과했지만 continuous swept/path-tube 증거는 아니다. 더구나 r621 splice generation report에는 independent_collision_validated=false가 명시되어 있다. 따라서 과거 시뮬레이션 성공을 최신 resident full-task lease로 승격하지 않는다.

2026-08-27 후속: direct-stop 전수 검사를 future-latch coverage와 구분

r627의 60 Hz 상태를 모두 독립 C2 brake 시작점으로 시험하니 precontact는 전부 가능했지만 attached 일부는 1초를 넘겼고 contained는 release command가 hand lower bound에 있어 position margin 0으로 전부 거절됐다. 처음에는 전체 nominal suffix를 더 느리게 retime하는 방안을 검토했으나, 이는 현재 protocol의 continue_nominal_to_future_abort_latch 의미를 무시하고 정상 실행 시간을 불필요하게 늘린다.

선택한 방향은 각 tick에서 즉시 새 brake를 만드는 것이 아니다. Reversible precontact에는 제한된 간격의 feasible latch를 두고, contact와 release 같은 irreversible 구간은 기존 certified command를 attached 또는 contained latch까지 완료한 뒤 정지한다. 모든 nominal sample은 phase-compatible 미래 latch 하나에 최대 continuation 시간 안으로 매핑되고, stale progress나 latch 누락은 resident route 선택이 아니라 독립 protective stop으로 처리한다.

2026-08-27 후속: 검사만 하지 않고 producer output에서 route를 생성

ad4a18e에서 1차 admission 비교에 남아 있던 source split을 제거했다. Abort planner, route command와 catalog는 이제 nominal template이나 producer-specific request에서 latch를 재구성하지 않고 실제 ResidentFullCommandOutput과 그 출력을 승인한 producer-neutral lease를 직접 소비한다. Bounded producer가 prefix를 바꿨더라도 route의 첫 arm·hand q/qd/qdd는 실제 output sample에서 생성되며, template은 event/lifecycle 의미의 별도 source로만 남는다.

관련 회귀 86개가 통과했고 conditional skip 1개가 유지됐다. 이 변경으로 exact splice source는 닫혔지만 route collision, dynamics, terminal region과 controller authority가 새로 승인된 것은 아니다.

남은 경계와 다음 단계

  1. r627 exact produced output, validated producer lease, event template, motion limits, contact, robot/object/workcell과 collision semantics를 최신 resident 계보로 source-close한다.
  2. Precontact와 attached/contained stationary-hand latch마다 brake를 생성하고 contact/release commit 구간은 certified safe-completion latch로 연결한다.
  3. Nominal 및 모든 abort route를 별도 GPU continuous collision·dynamics·terminal-region validator와 HPP-FCL parity로 검증한다.
  4. Accepted route만 startup CUDA slot에 올리고 각 phase fault를 actual Isaac articulation의 60 Hz 시간축에서 재생한다.

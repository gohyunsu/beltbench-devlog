ISSUE-019 · 2026-08-08 · bounded runtime update

정적 grasp 통과와 moving path 실행 가능성을 분리하고, retain → latch → one admission 순서를 고정한다.

AutoDex의 provider residual, scene collision, squeeze overlap, one-direction hold simulation, set-cover와 first-success 순서는 proposal 또는 정적 실험 근거이지 conveyor interception의 실행 기준이 아니다. Atlas를 통과한 grasp를 complete path-family로 다시 좁히고, runtime에는 fixed-size resident query와 cutoff 상태기계만 남겼다.

현재 효력: b84a168은 execution-blocked R3 query boundary다. 실제 compiled path, trusted projector, warm-start solver, independently reproduced continuous report, controller commit이 없으므로 로봇 명령을 생성하지 않는다.

구현 구조

  1. PathFamilyRuntimeRequest는 exact deployment bundle, interception episode, generation, robot motion, active execution/tracking, bounded family projection을 묶는다.
  2. ActivePathTrackingState는 arm/hand position·velocity·acceleration과 path-time alignment residual을 reusable path, tracking tube, validation report digest에 연결한다.
  3. ResidentPathFamilyEvaluator는 startup에 immutable family와 latch를 검증·정렬하고 runtime에는 fixed batch만 평가한다.
  4. PathFamilyRuntimeCoordinator는 episode당 하나이며 동일 generation은 idempotent, 변조 재사용은 오류, 과거 generation은 superseded 처리한다.
  5. Cutoff 전 권고 순서는 active retain, hysteresis를 통과한 certified latch, 한 번의 fixed-budget warm-start admission이다.
  6. Cutoff 이후 grasp와 topology는 고정하고 declared correction tube 안의 active correction만 남긴다. 밖이면 stop 권고다.

  • Local 관련 path-family·robot-motion·atlas·runtime 54개와 junjinyong 동일 54개가 통과했다.
  • Planning discovery 288개 중 OpenCV 전용 import 3개를 제외한 285개, calibration 환경 14개, 총 299개가 통과했다.
  • junjinyong policy-limit 8-family × 16-latch, 500 query는 p50 3.31 ms, p95 3.63 ms, p99 3.72 ms, maximum 5.50 ms였다.

아직 실행할 수 없는 이유

현재 family와 runtime request는 fixture뿐이며 실제 compiler output이 아니다. Fused ConveyorMotionState·FusedPlanarObjectTrack·calibration·prediction에서 각 family projection과 correction을 계산하는 trusted projector가 없다. Warm start는 admission만 있고 solver와 independent continuous validator가 없다. Tracking tube report 자체도 독립 재현되지 않았고 controller capability·dispatch·watchdog 계약도 없다.

다음 구현은 request를 수기로 채우는 fallback이 아니라 trusted projector와 measured state stream을 먼저 연결해야 한다. 그 뒤 warm-start backend agreement와 closed-loop simulation을 추가한다. 이 순서를 건너뛰면 현재 빠른 resident query는 실제 시스템의 latency나 안전성을 증명하지 못한다.

Execution-blocked path-family bundle이 offline 입력 경계이고, real-time architecture ADR이 전체 권한 순서를 정의한다.

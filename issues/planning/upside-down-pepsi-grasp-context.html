ISSUE-110 · 2026-08-31 · upside-down Pepsi grasp context

Upside-down Pepsi를 source-001 nearest grasp로 연결하지 않는다.

Nearest grasp는 같은 stable-pose context 안에서만 유효하다. 기존 Isaac RGB Pepsi 관측은 legacy upside_down pose였고 source-closed class binding은 이를 canonical source-002로 분류한다. 그러나 online registry에는 source-001 grasp만 있어, 잘못 연결하면 179도 이상 다른 자세의 grasp를 실행하게 된다.

현재 효력: beltbench@aef8607은 NAS의 source-002 atlas 42개를 정확한 context로 등록한다. 모두 unvalidated이므로 retrieval은 data availability를 알 수 있지만 planning과 execution은 계속 no-pick이다.

왜 nearest로 해결할 수 없는가

source-001과 source-002 representative는 약 179.35도 떨어져 있다. 이는 SE(3) threshold를 늘려 해결할 근접 오차가 아니라 stable-pose identity 불일치다. Exact object, canonical stable pose, hand와 capability가 먼저 일치한 뒤에만 그 context 내부의 top-K nearest를 계산한다.

Source-002 candidate가 registry에 없던 이전 상태는 no_registered_grasp_source를 냈다. 실제로는 proposal이 존재하므로 이 진단도 부정확했다. 새 registry는 세 context를 startup에서 재검증했고 manifest digest 456b279e...a48c00을 만들었다: banana/source-001 1개, Pepsi/source-001 41개, Pepsi/source-002 42개다.

Proposal이 있는데도 no-pick인 이유

Source-002의 512개 target-left proposal은 endpoint screening에서 46개, full intrinsic geometry diagnostic에서 44개를 남겼다. 하지만 모든 후보에 세 gate가 남아 있다.

  • Intrinsic validation protocol이 아직 provisional이다.
  • Complete stable-pose/open-set campaign이 아직 measured 상태가 아니다.
  • drop_release capability가 독립 검증되지 않았다.

Atlas의 validation_scope를 문자열만 바꿔 이 gate를 우회하지 않는다. Runtime interception은 unvalidated candidate를 제거하므로 현재 올바른 결과는 no-pick이다.

Stable pose evidence 재검토

Frozen-v3 Isaac settling에서 source-002 자체는 24/24 return, cross-class 0, unresolved 0이었다. 하지만 complete campaign은 global drop 192건 중 11건이 unresolved여서 5.729%를 기록했고 5.0% threshold를 넘었다. Pose 하나만 골라 complete set이 측정됐다고 주장할 수 없다. Threshold와 damping을 결과에 맞춰 조정하지 않고, 같은 acceptance로 repeatability를 재검증해야 한다.

다음 순서

  1. 같은 stable-pose/open-set threshold로 독립 settling campaign을 반복하고 complete set acceptance를 닫는다.
  2. 가정과 safety margin을 명시한 simulation intrinsic protocol을 승인한 뒤 46개 survivor만 재평가한다.
  3. Failure-free drop_release grasp만 offline_intrinsic으로 새 source artifact에 승격한다.
  4. 새 RGB run이 legacy alias가 아니라 canonical source-002 track을 publish하게 한다.
  5. 그때 동일 context top-K nearest, fresh interception, online command generation과 독립 collision validation을 실행한다.
  6. Qualified set이 비어 있을 때만 BODex 또는 다른 grasp generator를 다시 실행한다.

Online full-task authority reset과 partitioned self-collision이 이후 command 경계를 설명한다.

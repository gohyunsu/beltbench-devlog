ISSUE-017 · 2026-08-08 · path latching prerequisite

관절 위치가 가깝다는 이유만으로 움직이는 path에 연결하지 않는다.

기존 RuntimeRobotState는 arm과 hand의 위치만 기록한다. 같은 위치에서도 속도와 가속도가 다르면 필요한 제동 거리, collision timing, controller limit가 달라지므로 reusable path retain/latch/commit의 시작 상태로는 불충분하다. Path-family 구현 전에 controller-grade motion state와 state-box gate를 분리했다.

현재 효력: revision eaf6136은 robot/hand 중립 motion-state와 latch membership 검사를 구현한다. 이 membership은 필요조건일 뿐이며 certificate source, path tube, dynamics, correction과 cutoff 검증이 없으므로 command authority가 아니다.

문제, 원인, 결정

문제원인결정

xArm 관절 수나 Inspire 명칭으로 latch가 고정될 위험예시 robot/hand를 production schema로 일반화Manifest가 제공하는 named joint sequence를 exact identity로 사용
누락 derivative를 zero로 채우면 정지 상태처럼 보임편의 fallback이 측정 evidence를 대체Arm과 end-effector derivative 전체가 없으면 state 자체를 거부
State box 통과를 path 안전 증명으로 오해할 위험근접 상태와 collision/dynamics certificate를 같은 gate로 취급Membership과 path certificate authority를 명시적으로 분리

구현한 경계

  1. JointMotionDerivatives는 각 joint의 native SI velocity·acceleration과 정확한 순서를 보존한다.
  2. RuntimeRobotMotionState는 기존 timestamped position snapshot에 arm과 end-effector derivative를 결합하고 joint identity 불일치를 거부한다.
  3. JointMotionTarget과 JointMotionTolerance는 특정 robot joint 수를 가정하지 않는 path-phase 중심과 양의 per-joint 허용 오차를 정의한다.
  4. CertifiedRobotLatchRegion은 path family ID, path time, 허용 time error, arm/hand motion target·tolerance와 checksummed certificate reference를 가진다.
  5. latch_region_failures는 stale·future state, wrong path phase, joint substitution, position·velocity·acceleration 이탈을 한 번에 반환한다.

검증 결과

Round-trip, exact derivative identity, boolean payload, fresh/stale/future time, path phase, position·velocity·acceleration 이탈, arm joint substitution, positive tolerance를 검사했다. 관련 test 27개와 compile이 통과했다.

전체 planning 수집 267개 중 OpenCV 전용 import 3개를 제외한 실제 264개가 통과했고, calibration 환경 14개도 통과해 총 278개를 확인했다. junjinyong 서버의 고정 planning 환경에서도 관련 33개가 통과했다.

다음 단계

  • Grasp·yaw context·lateral position·belt speed·intercept cell을 reusable path family에 연결한다.
  • Latch certificate file의 schema와 source digest를 deployment-bundle startup에서 검증한다.
  • Uncertainty-inflated path tube, collision·joint·singularity·tracking margin, hand-close timing과 stop segment를 hard gate로 추가한다.
  • Cutoff 전 retain/latch/한 번의 bounded warm start, cutoff 후 phase correction 또는 abort만 허용한다.

실시간 conveyor architecture ADR의 R2 prerequisite이며, runtime event session은 이후 latch·abort 결정을 기록한다.

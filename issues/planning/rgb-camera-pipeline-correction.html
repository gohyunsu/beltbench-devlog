ISSUE-089 · 2026-08-26 · physical target is RGB, not RGB-D

깊이를 대체하는 fallback이 아니라, RGB-only 관측 계약과 검증 순서를 다시 닫는다.

실제 장비의 카메라가 RGB라는 사실을 기준으로 전체 D1 경계를 다시 감사했다. Metric 위치는 depth image가 아니라 알려진 CAD scale, stable tabletop pose, camera calibration과 belt plane에서 얻고, 초기 pose 이후의 이동은 encoder가 전파한다. Isaac RGB background mask와 FoundPose를 바로 연결한 방법은 개발 분할에서 실패했으므로 threshold를 느슨하게 하지 않고, qualified YOLOE mask와 source-matched RGB yaw backend로 simulation diagnostic을 다시 구성했다.

현재 판정, 2026-08-27: a541e28에서 raw RGB → resident two-view YOLOE → known-plane position → source-matched RGB yaw → encoder → event selection → collision/handoff → PhysX grasp/drop의 선언된 simulation diagnostic이 r488에서 실제시간으로 통과했다. 다만 known-plane metric position의 독립 holdout, unmodified hand target, physical-camera qualification과 hardware safety가 남아 professor_demo_ready=false와 hardware authority false를 유지한다.

고정한 실제 시스템 계약

synchronized raw RGB cameras
  -> calibration-bound in-memory rectification
  -> one batched object-mask backend
  -> one-shot RGB-to-CAD planar [x, y, yaw] acquisition
  -> exact measurement-time encoder registration
  -> 60 Hz constant-yaw translation propagation
  -> prevalidated intercept family selection
  -> collision gate -> future-start controller lease
  -> measured contact, release, bin containment
  • Object identity와 stable tabletop pose ID는 trial 전에 주어진다.
  • 초기 belt-frame x, y와 yaw는 RGB에서 측정한다. 물체가 belt 위에서 추가 회전하지 않는다는 가정만 사용한다.
  • Camera intrinsic/extrinsic, belt plane, belt axis, CAD scale과 stable pose가 metric scale을 제공한다. Observed depth, zero depth, simulator pose fallback은 금지한다.
  • FoundPose는 상류 event에서 한 번 실행할 수 있지만 매 frame stage가 아니다. 이후 위치는 encoder가 60 Hz로 전파한다.
  • GoTrack은 qualified initial pose 이후 선택 가능한 correction/tracking backend다. 초기 mask와 pose 실패를 대체하지 않는다.

왜 SAM3를 그대로 online에 넣지 않는가

AutoDex의 새 init 구조도 SAM3 mask와 FoundPose를 episode 초기에 한 번 실행하고 GoTrack으로 이어간다. 그러나 AutoDex 문서의 SAM3 mask stage는 약 2.5 s이고 전체 과거 init은 수십 초였다. BeltBench의 현재 upstream acquisition budget은 0.975 s이므로 동일 코드를 직렬로 복사하면 실제시간 event를 놓친다.

SAM3는 native RGB의 offline label 생성과 품질 비교에 활용할 수 있다. Online 후보는 resident batched YOLOE/FastSAM 또는 Pepsi용 compact segmenter로 제한하고, 두 camera를 한 batch로 처리한다. 선택 기준은 보기 좋은 mask가 아니라 mask IoU/경계 오차, downstream pose acceptance와 x/y/yaw error, cross-view 일관성, p95 latency와 source/weight digest다.

다음 구현 및 승격 순서

  1. 완료: YOLOE learned mask, source-matched simulation yaw, exact weight/source admission과 actual-time D1-D3 lifecycle을 연결했다.
  2. 다음: Known-plane metric position을 independent simulation holdout에서 bias, covariance, camera disagreement, trigger coverage로 검증한다.
  3. 다음: Physical RGB rig에서 hardware synchronization, in-memory rectification, exposure/blur/occlusion, segmentation과 x/y/yaw를 별도 native holdout으로 qualification한다.
  4. 다음: CPU startup certificate만 사용하는 현재 collision 경계를 resident GPU collision gate와 비교 qualification하고, 실제 decision latency 감소가 있을 때만 승격한다.
  5. 다음: Guarded contact의 run-to-run force와 containment repeatability를 multi-seed/multi-run protocol로 측정한 뒤 controller/stop route와 supervised hardware safety를 검증한다.

ISSUE-029 · 2026-08-09 · synchronized event trajectory

AutoDex grasp를 moving pick에 쓰기 전에 arm과 hand의 실제 시간 사건을 하나의 검증 경계로 묶는다.

정적 grasp가 통과했다는 사실과 moving conveyor에서 접촉할 수 있다는 사실 사이에는 동기 궤적이 필요하다. Arm과 hand의 위치만 그럴듯하게 보간하지 않고, closure 시작, first contact, closure 완료, attach를 같은 시간축의 q, qdot, qddot 상태로 고정했다. 구간 내부 관절 한계는 sampling이 아니라 다항식 극값으로 검사한다. 이 reference는 시간 배정 optimizer나 continuous collision authority가 아니다.

현재 효력: source commit 1b3e948이 동기 event 계약, piecewise-quintic reference, analytic joint-limit assessment, grasp/connector 결속과 moving-contact adapter를 구현한다. 실제 xArm/Inspire controller trajectory, continuous collision, chase interval과 hardware closure가 없으므로 모든 결과는 execution_blocked다.

AutoDex 기준을 다시 확인한 결론

감사 대상은 public willi19/autodex-code:main 5ada1c0이다. BODex residual과 provider order는 생성 provenance이고, static sphere collision, squeeze overlap, 고정 0.1 kg MuJoCo hold, adaptive scene당 다섯 survivor, binary set cover와 runtime first-success planning은 정적 후보를 줄이는 절차다. 어느 단계도 moving object와 tool의 접촉 상대 속도, arm-hand 동기 closure, event deadline 또는 controller tracking을 검사하지 않는다.

채택한 실행 전 filter

  1. Grasp ancestry: object, stable pose, hand, grasp ID와 complete semantic grasp payload hash가 일치해야 한다.
  2. Connector ancestry: connector ID뿐 아니라 arm_tip_from_hand_root transform hash가 일치해야 한다. AutoDex hand root를 arm flange로 직접 간주하지 않는다.
  3. 동기 상태: 모든 waypoint가 같은 arm/hand named-joint order와 하나의 시간축에서 q, qdot, qddot를 가져야 한다.
  4. Event window: 각 사건의 지정 시각이 선언된 window 안에 있고 사건 tuple이 시간 순서를 거슬러서는 안 된다.
  5. Closure semantics: hand_close_start < contact < hand_close_complete <= attach를 요구한다. Closure 시작은 pregrasp command, 완료와 attach는 final grasp command 및 prescribed zero hand velocity/acceleration이어야 한다. First contact의 hand state는 닫히는 중인 intermediate state를 허용한다.
  6. Continuous joint limits: piecewise quintic의 position, velocity, acceleration, jerk 극값을 polynomial root로 구해 joint별 독립 hard gate로 검사한다.
  7. Moving contact: contact의 exact arm q/qdot와 Jacobian, object pose·twist로 pose error와 상대 선·각속도를 독립 검사한다.

모든 hard gate를 통과한 뒤에만 normalized slack의 deterministic lexicographic maximin으로 후보를 비교한다. Provider order, weighted sum, 가장 먼 intercept와 첫 planning 성공은 최종 선택 규칙이 아니다.

구현한 reference와 의도적 한계

EventScheduledTrajectoryRequest는 exact geometric-path, grasp, connector transform, motion-limit profile digest를 저장한다. Arm과 hand를 따로 retime하지 않고 동일한 waypoint time과 semantic event를 사용한다. Artifact는 write-once이며 assessment는 request와 limit profile의 canonical hash에서 완전히 재현해야 한다.

reference.event_piecewise_quintic.v1는 각 구간 경계의 위치·속도·가속도를 정확히 만족하는 normalized-time quintic을 만든다. Position extrema는 velocity root, velocity extrema는 acceleration root, acceleration extrema는 jerk root, jerk extrema는 snap root와 구간 양 끝에서 계산한다. 따라서 frame stride 사이의 위반도 검출한다.

이 구현은 schedule allocator가 아니다. Event 시각을 선택하거나 deadline 안에 재배치하지 않으며 collision-free geometric path를 만들지 않는다. Quintic은 waypoint 사이에서 원래 path를 벗어나거나 overshoot할 수 있으므로 exact interpolated arm-hand-connector-object geometry에 대한 continuous/swept collision 검증이 반드시 다시 필요하다. Draft joint limits의 통과도 manufacturer 또는 measured authority를 만들지 않는다.

Ruckig Community는 local state-to-state latch·stop·작은 correction 후보로 남긴다. Intermediate waypoint는 Community에서 local solver가 아니며 exact multi-event duration도 이 task에 필요한 방식으로 보장하지 않으므로 main task path의 임시 fallback으로 설치하지 않았다. Position-only playback finite difference도 contact qdot를 보존하지 않아 폐기했다.

검증 결과

  • 새 event trajectory, moving contact, grasp library focused test 26/26이 local planning 환경에서 통과했다.
  • 최종 planning full discovery는 432개를 수집했고 OpenCV import 3개를 제외한 429개가 통과했다. 분리된 calibration 환경에서 해당 module의 실제 test 14/14가 통과했다.
  • Public export는 contracts 335, planning 89개이며 중복 없이 import됐다.
  • junjinyong PBS job 115169는 source 1b3e948, CPU 1개, 4 GB, GPU 0개에서 관련 34/34를 10.567초에 통과했고 scheduler와 run status 모두 exit 0을 기록했다.
  • 같은 PBS status의 compute_minus_filesystem_clock_s=-367, timing_evidence_authorized=false를 보존했다. 10.567초는 test log duration일 뿐 real-time planning 성능 근거가 아니다.

다음 구현 순서

  1. Offline compiler가 bounded belt speed·yaw·intercept cell마다 collision-free geometric path와 semantic event window를 생성한다.
  2. Event window와 deadline을 보존하는 local time-parameterizer를 별도 capability로 구현하고 이 quintic reference와 agreement를 검사한다.
  3. Exact interpolated arm·hand·connector·object path의 continuous/swept collision과 chase interval moving-contact를 검증한다.
  4. 같은 actual-time trajectory를 desired stream과 Viser 자동 반복 재생에 연결하되 simulation feedback과 execution evidence를 구분한다.
  5. Hardware가 준비된 뒤 controller tracking, hand closing/attachment, connector metrology, moving-pick reliability를 측정해 physical commit authority를 별도로 연다.

관련 배경은 path validation authority, real-time conveyor architecture, AutoDex selection 감사에 이어서 기록한다.

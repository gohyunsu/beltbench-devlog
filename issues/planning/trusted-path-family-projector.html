ISSUE-020 · 2026-08-08 · trusted projection

측정 track을 수기로 꾸민 runtime 후보가 아니라 검증 가능한 path-family projection으로 변환한다.

AutoDex grasp filter는 정적 proposal을 줄이는 근거이고, conveyor grasp 실행 가능성은 아니다. Fused planar track, encoder, calibration, yaw uncertainty와 고정된 path schedule을 한 projection evidence로 묶고, 고려한 모든 resident family가 통과 또는 명시적 거부 중 하나에만 속하도록 만들었다.

현재 효력: c077029은 continuous horizon bracket을, ef1ab88은 trusted projector를 구현한다. 여전히 execution-blocked이며 controller 명령 권한은 없다.

현재 선택 규칙

  1. Object, stable pose, hand, provider revision과 source checksum이 정확히 일치하지 않으면 grasp proposal을 사용하지 않는다.
  2. Named contact, allowed penetration, non-contact·self·support clearance, signed force·moment task wrench, approach·closure·release를 arm-independent intrinsic hard gate로 검사한다.
  3. Robot deployment atlas는 yaw uncertainty와 continuous planning horizon을 둘러싼 모든 yaw × horizon cell의 grasp 교집합만 허용한다.
  4. Path family는 atlas보다 좁은 lateral·speed·intercept·horizon support, complete phase, collision·joint·singularity·timing slack, latch·correction·stop evidence를 가져야 한다.
  5. Runtime은 fresh fused track·encoder·calibration과 robot position·velocity·acceleration을 검사하고, active retain → certified latch → 한 번의 bounded warm-start admission 순서만 허용한다.
  6. 모든 hard gate 통과 후에만 전체 normalized slack을 작은 값부터 정렬한 lexicographic maximin으로 비교하고, switch에는 bottleneck hysteresis를 추가한다.

Provider score, grasp residual, coverage count, 거리상 가장 먼 intercept 또는 첫 successful plan은 어떤 hard gate도 보상하지 못한다.

검증 결과

  • Continuous horizon, explicit anchor, fixed active contact, prestart phase, identity/tracking failure, request mutation, cutoff, active-family priority, compute-budget failure를 테스트했다.
  • 관련 tracking·atlas·path-family·runtime 54개가 로컬에서 통과했다.
  • Planning discovery 300개 중 OpenCV 전용 import 3개를 제외한 297개와 calibration 환경 14개, 실제 총 311개가 통과했다.
  • Projector와 resident evaluator를 합친 local 8-family 500회는 p50 6.30 ms, p95 8.30 ms, p99 10.09 ms, max 11.73 ms였다.

남은 판단과 다음 구현

현재 빠른 부분은 이미 compile된 family를 측정 상태에 투영하고 고르는 단계뿐이다. Fixture의 reusable path, tracking tube, continuous report를 실제 compiler와 독립 validator가 아직 생성·재현하지 않는다. TrustedPathFamilyProjectionBatch도 직렬화 가능한 evidence이므로 최종 시스템에서는 임의 caller가 만든 객체를 신뢰하지 않고 projector와 coordinator를 소유하는 runtime session 경계가 필요하다.

다음 단계는 grasp 점수를 추가하는 것이 아니다. 한 번만 허용된 warm-start admission이 deadline 안에 complete trajectory, dynamics, continuous collision, correction support와 stop path evidence를 반환하거나 명시적으로 실패하는 계약을 구현한다. 그 뒤 post-contact lift·bin drop handoff, controller commit·watchdog, actual-time closed-loop simulation을 연결한다.

Bounded runtime state machine이 다음 권한 계층이고, real-time architecture ADR이 전체 순서를 정의한다.

Real-world manipulation benchmark

From a stable tabletop grasp to a moving-belt benchmark.

BeltBench compares a modular, perception–planning–control stack with a VLA policy on the same pick-and-place task. The first milestone recreates Mingi's AutoDex/ParaDex system on the xArm workcell; the final benchmark evaluates moving objects, timing, recovery, and robustness.

Baseline protocol

First measurable deliverable

The first goal is deliberately static: it makes calibration, perception, planning, and execution failures observable before motion timing is introduced.

ItemDefinition
Objects10 objects already seen in AutoDex training
Trials10 attempts per object (100 total)
TaskTabletop object → successful grasp → place inside basket
Primary metricTask success ratio, per object and aggregate
Secondary metricsPerception/planning/execution latency, grasp precision, failure type, recovery outcome
